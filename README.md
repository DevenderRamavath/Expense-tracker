# Expense Tracker

A simple, responsive expense tracker built with React and Vite.

## Features

- Add income and expense transactions with categories and dates
- View total balance, income, and expenses
- Search transactions and filter by transaction type
- Export transactions to a CSV file
- Delete individual transactions or clear all transactions
- Browser storage persists data between visits

## Run locally

```powershell
npm install
npm run dev
```

Then open the local URL printed by Vite (usually `http://localhost:5173`).
